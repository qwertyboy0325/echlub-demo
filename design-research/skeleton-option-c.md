# Skeleton Option C — "Dual Canvas"

## Concept

Split screen: **left = Shared world** (Exchange + arrangement), **right = Personal world** (full editor). Presenter can maximize either side. Radically different from A/B — emphasizes simultaneous shared vs personal context without miniatures.

## Layout — Default (1440×900)

```text
┌─────────────────────────────────────────────────────────────┐
│ Transport │ Presenter: Split │ Follow │ Master │ Bleed        │
├────────────────────────────┬────────────────────────────────┤
│ SHARED CANVAS (50%)        │ PERSONAL CANVAS (50%)          │
│                            │                                │
│ Exchange board (top 40%)   │  Primary editor (75%)          │
│ Kanban: Draft|Shared|Stage │  MIDI / Step / Devices         │
│                            │                                │
│ Arrangement strip (60%)    │  Personal clip browser (25%)   │
│ clip slots, playhead       │                                │
│                            │                                │
│ Presence dots on margin    │  Task profile switcher         │
└────────────────────────────┴────────────────────────────────┘
```

## Layout — Mixer mode

- Personal canvas becomes Mixer + Live Control Dock (70% of right half)
- Shared canvas unchanged — audience sees arrangement while mix happens

## Layout — Global maximize

- Shared canvas 85%; personal collapses to 48px icon strip
- Used during arrangement payoff moments

## Presenter navigation

- Split | Shared-max | Personal-max toggles
- Follow Active enlarges side of active participant

## Collaboration without mini editors

- Shared canvas is artifact-centric (cards with state, not DAW chrome)
- Personal canvas is full editor — only one shown
- Never more than one personal editor visible

## Exchange as anchor

Kanban columns map to lifecycle states; drag across column = workflow transition.

## Live Control Dock

Occupies lower 50% of personal canvas in Mixer mode; 8 slots horizontal.

## Risks

- 50/50 split leaves both sides cramped at 1280×720
- Kanban may feel "project management" not "music studio"
- Harder to show 3+ participants simultaneously

## First-impression

"Shared board + my studio" — strong for collaboration narrative, weaker for arrangement focus.

## When to choose over B

- Owner prioritizes visible shared/personal dichotomy over persistent rails
- Demo script emphasizes handoff moments over continuous arrangement view
